Editorial approach

Updates with context, evidence and clear status.

Spacefield news is intended to be factual rather than promotional. Each update should state what has happened, what remains in development and where readers can find the related research, release or company record.

This matters because scientific and software milestones can easily be overstated. A completed benchmark is not the same as external validation. A frozen software package is not the same as a public release. A research candidate is not the same as an experimentally confirmed result.

News items will therefore use clear labels such as preparing, in development, frozen, validated, released or externally evaluated where appropriate.

VerifiedMaterial facts should be supported by a public or internal record.
ScopedAnnouncements should state what the milestone does and does not establish.
PermanentImportant updates should remain accessible rather than disappearing in a social feed.

Communication policy

What readers should expect from Spacefield announcements.

Public updates should be useful, accurate and appropriately cautious.

Where an announcement relates to scientific performance, software availability or candidate molecules, the page should link to the relevant evidence and state the limits of the claim.

01
No unsupported scientific claims

Computational predictions will not be presented as proof of therapeutic efficacy, safety or clinical value.

02
No implied public access

A release announcement will state whether software, models or documentation are public, private or controlled.

03
No hidden status changes

Updates will distinguish active development, frozen checkpoints, release candidates and authorised releases.

04
Corrections remain visible

Material corrections or superseded statements should be linked to the original announcement where practical.
